🎮 Neon Squad — Team Deathmatch

Neon Squad is a small Python/Pygame team-deathmatch arena game inspired by multiplayer shooter games.

The project focuses on basic game-development concepts such as player movement, aiming, projectiles, health, teams, simple AI, scoring, and respawning.

✨ Features

- 🎮 Player-controlled character
- 🔵 Blue team vs 🔴 Red team
- 🏃 WASD movement
- 🎯 Mouse aiming
- ⚡ Fictional blaster projectiles
- ❤️ Health system
- 🤖 Basic enemy AI
- 🔄 Automatic respawning
- 🏆 Team-based combat
- 📊 Score tracking
- 🗺️ Simple arena

🛠️ Technologies

- Python 3
- Pygame

💻 Installation

Make sure Python 3 is installed.

Clone the repository:

git clone https://github.com/YOUR-USERNAME/neon-squad.git

Open the project folder:

cd neon-squad

Install the required package:

pip install -r requirements.txt

▶️ Run the Game

Start the game using:

python main.py

🧠 Game Mechanics

Player

The player belongs to the Blue team and can move around the arena using WASD.

Blaster

Clicking the left mouse button launches a fictional energy projectile toward the mouse cursor.

Health

Every character starts with 100 health.

Each projectile deals 25 damage.

When a character's health reaches zero, the character is temporarily removed from the arena and then respawns.

Teams

There are two teams:

- Blue Team
- Red Team

Characters cannot damage members of their own team.

Bot AI

Enemy bots search for opponents and move toward them.

Bots also automatically fire their blasters at nearby opponents.
